Войдите через Google, и идеи, дела, цены, фильмы, ключи для «Кино» и вложения сохранятся на вашем Google Диске (папка «iLife») и появятся на других устройствах — на телефоне, планшете и ПК.

Открыть папку на Диске
Автоматическая синхронизацияСразу после изменений, при открытии и раз в минуту, пока приложение на экране
Ключи тоже на ДискКлючи TMDB, OMDb, ПоискКино, ИИ, YouTube, Client ID Spotify и токен Telegram-бота лежат в вашем файле iLife/ilife_data.json и подтягиваются на новом устройстве. Выключите, если не хотите хранить их на Диске

Вложения тоже на ДискКартинки, музыка, голосовые записи и файлы (до 50 МБ каждый). Без них на других устройствах будут только тексты
Как подключить — пошагово
  1. Откройте console.cloud.google.com под своим аккаунтом Google. Вверху выберите проект (можно тот же, что у My Money) или создайте новый.
  2. APIs & Services → Library → найдите Google Drive API → Enable.
  3. Google Auth Platform (или «OAuth consent screen»): тип External, статус Testing; в Test users добавьте свой Gmail. В Data access добавьте права …/auth/drive.file, openid, email, profile.
  4. Clients → Create client → тип Web application. В Authorized JavaScript origins нажмите Add URI и вставьте адрес из поля выше (только начало адреса: https://ЛОГИН.github.io, без названия репозитория и без слэша в конце). Если My Money уже на том же github.io, ничего добавлять не нужно. Redirect URI не нужен. Create.
  5. Скопируйте Client ID (вида 123456789012-abc….apps.googleusercontent.com) и вставьте в поле выше. Он не секретный. Чтобы он сразу был на всех устройствах, впишите его в файл js/config.js на GitHub (образец — js/config.example.js).
  6. Нажмите «Войти через Google». Google скажет «Приложение не проверено» — это нормально для личного приложения: Дополнительно → Перейти и отметьте доступ к Google Диску. Если окно не открылось — разрешите всплывающие окна для сайта.

Приложение видит на Диске только свои файлы (доступ drive.file). Вход Google действует 1 час: потом нажмите «Продолжить синхронизацию» — изменения до этого сохраняются на устройстве и не теряются. Внутри APK-обёртки вход Google не работает — пользуйтесь Chrome или установите сайт на главный экран.

SpotifyНе подключён

Как подключить — пошагово
  1. Premium у владельца приложения. С февраля 2026 Spotify разрешает приложения в режиме разработки только владельцам с подпиской Premium (и не более 5 пользователей на приложение). Для личного пользования этого достаточно: владелец — вы.
  2. Откройте developer.spotify.com/dashboard, войдите своим аккаунтом Spotify и нажмите Create app.
  3. Заполните: App name — iLife, App description — личные заметки. В поле Redirect URI вставьте адрес из поля выше (кнопка «копировать») и нажмите Add. Адрес должен совпадать до символа: https://, имя сайта, слэш в конце. «localhost» Spotify не принимает; для проверки на компьютере используйте http://127.0.0.1:8080/. В списке «Which API/SDKs» отметьте Web API, согласитесь с условиями и нажмите Save.
  4. Откройте созданное приложение → Settings и скопируйте Client ID. Client Secret не нужен — никуда его не вставляйте.
  5. В том же приложении откройте User Management: в режиме разработки войти могут только добавленные люди. Если вы слушаете музыку под тем же аккаунтом, под которым создали приложение, ничего делать не нужно; иначе добавьте имя и e-mail своего аккаунта Spotify.
  6. Вернитесь сюда, вставьте Client ID и нажмите «Подключить Spotify». Откроется страница Spotify — войдите и нажмите Agree (приложение получает только право читать, что играет и что вы недавно слушали). Вы вернётесь в iLife, статус станет «Подключён».
  7. Как пользоваться. На странице «Идеи» нажмите кнопку Spotify: «Взять то, что играет сейчас» подставит песню, исполнителя, альбом и обложку; ниже — недавно слушанное и поиск по Spotify. Трек сохранится в заметке вместе с обложкой.

Токены хранятся только на этом устройстве, в браузере; отключить доступ можно кнопкой «Отключить» или на странице spotify.com/account/apps. Если приложение открыто внутри APK-обёртки, подключайтесь в Chrome: обёртка и браузер хранят токены отдельно.

YouTubeНе подключён

Нужен, чтобы кнопка «YouTube» на странице «Идеи» искала песни: название, исполнитель, обложка и ссылка. Без ключа песню можно добавить по ссылке или вручную.

Где взять ключ — пошагово
  1. Откройте console.cloud.google.com под своим аккаунтом Google и выберите проект (можно тот же, что для Google Диска).
  2. APIs & Services → Library → найдите YouTube Data API v3 → Enable.
  3. APIs & Services → Credentials → Create credentials → API key. Скопируйте ключ (он начинается с AIza).
  4. Чтобы ключ не смог использовать кто-то другой, откройте его (Edit API key): в Application restrictions выберите Websites и добавьте адрес сайта вида https://ВАШ-ЛОГИН.github.io/* (с «/*» на конце); в API restrictions выберите Restrict key → YouTube Data API v3 → Save. Ограничения вступают в силу через несколько минут.
  5. Вставьте ключ в поле выше и нажмите «Проверить ключ». Затем на странице «Идеи» нажмите «YouTube»: поиск по названию или исполнителю, режим «Музыка» или «Все видео», вставка ссылки и список недавно выбранных песен.

Бесплатный лимит — 10 000 «единиц» в сутки; один поиск стоит 100, то есть около 100 поисков в день (вставка ссылки почти ничего не стоит). Ключ хранится на этом устройстве и, если включено «Ключи тоже на Диск», в вашем файле на Google Диске; в файл резервной копии он не попадает.

Telegram-каналНе настроено

Нужно для кнопки «Забрать из канала» на странице «Идеи»: бот читает посты вашего канала и приложение делает из них идеи. Для способа «Из экспорта Telegram» бот не нужен.

Ставить тег #telegramИдеи из канала легко отфильтровать одним нажатием
Скачивать фото и файлыКартинки, голосовые, аудио и файлы до 20 МБ (ограничение Telegram для ботов) сохраняются вместе с идеей
Забирать автоматическиПри открытии приложения и раз в 5 минут: новые посты сразу становятся идеями, без окна просмотра. Рекомендуется, потому что бот хранит посты только сутки

Как подключить — пошагово
  1. Бот. В Telegram откройте @BotFather → /newbot → имя и логин (оканчивается на bot). BotFather пришлёт токен вида 123456789:AA… — вставьте его в поле выше.
  2. Канал. Создайте канал (удобно — закрытый, только для идей) или возьмите свой. Управление каналом → Администраторы → Добавить администратора → найдите своего бота и сохраните: без этого бот не видит посты канала.
  3. Опубликуйте в канале любой пост и нажмите «Проверить бота и канал»: приложение покажет найденные каналы и их номера. У открытого канала впишите @имя, у закрытого — номер вида -1001234567890. Поле можно оставить пустым — тогда берутся все каналы, где бот администратор.
  4. На странице «Идеи» нажмите «Забрать из канала». Бот отдаёт то, что опубликовано за последние 24 часа, и дальше — всё новое. Приложение покажет список будущих идей: уберите лишнее и нажмите «Добавить». Вложения (фото, голосовые, файлы) прикрепляются к идее.
  5. Старые посты — через экспорт. Telegram Desktop → откройте канал → ⋮ → «Экспорт истории чата» → отметьте фото (и файлы) → формат JSON (лучше) или HTML → «Экспортировать». Папку заархивируйте в ZIP и на странице «Идеи» нажмите «Выбрать экспорт». Можно выбрать и один файл result.json (тогда будут только тексты).
  6. ИИ (по желанию) берётся из блока «Кино: базы и оценки» ниже — Gemini или Claude. Он получает только тексты постов (картинки не отправляются) и предлагает хештеги, даты событий и разбивку списков на отдельные идеи. Без ИИ каждая запись или альбом становится одной идеей с хештегами из самого поста.

Токен хранится на этом устройстве и, если включено «Ключи тоже на Диск», в вашем файле на Google Диске; в файл резервной копии он не попадает. Бот читает только каналы, куда вы его добавили, и ничего не публикует. Один и тот же пост не добавится дважды; удалённые вами идеи обратно не возвращаются.

Кино: базы и оценкиНе настроено

Обложки, режиссёры, актёры и оценки берутся из бесплатных баз. Ключи вводятся один раз: после входа через Google они сами сохраняются в вашем файле на Google Диске и подтягиваются на других устройствах (это можно выключить в блоке «Google Диск» выше). В файл резервной копии ключи не попадают.

Звать ИИ автоматическиЕсли по тексту на скриншоте фильм не нашёлся. Картинка при этом отправляется в сервис ИИ
Где взять ключи — пошагово
  1. TMDB (бесплатно, для личного пользования). Зарегистрируйтесь на themoviedb.org, откройте Settings → API (прямая ссылка) и нажмите Create. Тип — Developer, назначение — личное некоммерческое (название — iLife, описание — «личный список фильмов»). Скопируйте API Key (32 символа) или длинный API Read Access Token — подойдёт любой — и вставьте в поле выше.
  2. OMDb (бесплатно, 1000 запросов в сутки). Откройте omdbapi.com/apikey.aspx, выберите FREE, укажите e-mail. На почту придёт письмо: обязательно нажмите в нём ссылку активации — без этого ключ не работает. Ключ из письма вставьте в поле.
  3. ПоискКино (бесплатно, 200 запросов в сутки). В Telegram откройте бота @poiskkinodev_bot и получите ключ (сайт сервиса — poiskkino.dev). Вставьте в поле. Это даёт оценку Кинопоиска; без него она просто не показывается.
  4. ИИ — по желанию. Нужен, только если на скриншоте нет названия (кадр из фильма, афиша с рисованными буквами). Ключ Gemini: aistudio.google.com/apikey (есть бесплатный лимит). Ключ Claude: console.anthropic.com (платно, копейки за снимок). Если сервис переименует модель и появится ошибка «модель не найдена», впишите актуальное название в поле «Название модели».
  5. Нажмите «Проверить подключение»: напротив каждого сервиса появится «работает» или причина ошибки. После этого на странице «Кино» поиск, обложки, оценки и распознавание заработают.

Приложение ходит в эти сервисы напрямую из вашего браузера, без своего сервера. Распознавание текста на скриншоте (Tesseract) идёт на устройстве: при первом запуске скачивается модуль и словари, около 15 МБ, дальше берутся из кеша браузера. Подключённый ИИ получает только те картинки, которые вы отправили на распознавание.

Данные о фильмах предоставлены TMDB. This product uses the TMDB API but is not endorsed or certified by TMDB. Рейтинги IMDb, Rotten Tomatoes и Metacritic — через OMDb, Кинопоиска — через ПоискКино.

Журнал изменений

1.5.0 Мое_совсек

  • Новая страница «Мое_совсек» в меню: фото и GIF из экспорта Telegram (ZIP, result.json или messages.html). Меню импорта такое же, как «Telegram-канал» на странице «Идеи», только без бота: берётся экспорт из файла, и только картинки (видео добавим позже).
  • Из каждой пары «оригинал и копия хуже качеством» остаётся лучшая: миниатюры экспорта (…_thumb) не берутся, а тот же кадр в меньшем разрешении или пережатый дубль заменяется версией с лучшим разрешением (при равенстве — тяжелее по размеру). Файлы самого экспорта не трогаются.
  • Папки: «Картинки» и «GIF» — год → месяц → день; «Хештеги» — по хештегам из подписей (и от ИИ, если включить); «Актёры» — по именам. Файлы не дублируются, папки виртуальные.
  • Актёров по лицам приложение не определяет. Имя попадает в «Актёры» из подписи к фото, из надписи на самой картинке (если включён ИИ — он только читает текст) или вы указываете вручную: «Хештеги и актёры» у фото или у нескольких выбранных.
  • Три вида: «Список», «Мелкие» и «Крупные» файлы; порядок — новые, старые, тяжёлые; режим «Выбрать» для нескольких фото; просмотр с листанием.
  • «Сохранить папку» — у любой папки (год, месяц, день, актёр, хештег, GIF, всё сразу) архивом ZIP с сохранением вложенных папок; «Сохранить фото» — у каждого отдельного фото.
  • Фото хранятся на устройстве и синхронизируются между устройствами через Google Диск в отдельную папку «iLife / Мое_совсек» (метаданные — в общем файле данных). Для этого на всех устройствах должна быть версия 1.5.0.

1.4.0 Telegram · YouTube · логотип

  • «Идеи → Telegram-канал»: два способа превратить посты канала в идеи. Первый — «Забрать из канала»: приложение само читает канал через вашего бота (фото, голосовые и файлы прикрепляются к идее). Второй — «Выбрать экспорт»: ZIP, JSON или HTML из экспорта Telegram Desktop для старых постов.
  • ИИ (тот же Gemini или Claude, что в блоке «Кино») по желанию подбирает каждой идее свои хештеги, находит даты событий в тексте и делит посты-списки на отдельные идеи. Перед добавлением открывается список с галочками; в «Настройках» можно включить автоматическое добавление. Идея запоминает исходную дату поста, а дата события ищется в поиске и показывается в заметке.
  • Музыка: рядом со Spotify появилась кнопка «YouTube» — поиск песен в том же удобном виде (обложка, название, исполнитель, длина), режимы «Музыка» и «Все видео», вставка ссылки, список недавно выбранных и ручной ввод. Нужен ключ YouTube Data API: «Настройки → YouTube».
  • Ваша картинка стала логотипом: на сайте, во вкладке браузера и на значке установленного приложения (Chrome на телефоне). Версия показана рядом с логотипом на главной, на экране блокировки и в боковой панели; нажатие на неё открывает этот журнал. Приложение помечено как личное и не предназначенное для коммерческого использования.
  • Новые заметки в списке всегда идут по дате поста, поэтому старые посты из Telegram встают на своё место. В «Изменить идею» можно задать или убрать дату события. Токен бота Telegram и ключ YouTube синхронизируются через Google Диск вместе с остальными ключами.

1.3.1 Синхронизация

  • «Настройки → Google Диск» показывает, есть ли ключи на Диске, когда они менялись и какой версией приложения записан файл — сразу видно, если другое устройство ещё на старой версии.
  • Приложение при каждом открытии сверяется с сайтом, поэтому новая версия подхватывается без ожидания (раньше браузер мог до 10 минут показывать старые файлы).

1.3.0 Ключи

  • Ключи TMDB, OMDb, ПоискКино, ИИ и Client ID Spotify теперь сохраняются в вашем файле на Google Диске и сами подтягиваются на других устройствах после входа через Google — вводить их второй раз не нужно. Каждый ключ синхронизируется отдельно: ключ с телефона не затирает остальные.
  • Выключатель «Ключи тоже на Диск» — в «Настройки → Google Диск». В файл резервной копии ключи по-прежнему не попадают.

1.2.1 ИИ

  • Если Gemini отвечает «503 — сервер перегружен», приложение само повторяет запрос и пробует запасные модели (3.6 Flash, 3.5 Flash-Lite), если вы не вписали свою. Если не вышло, объясняет причину, а у скриншота остаётся кнопка «Спросить ИИ ещё раз».

1.2.0 Кино

  • Новый раздел «Кино»: «Смотрю сейчас», «Список для просмотра» и «Просмотрено». У каждого фильма обложка, название, оценки (Кинопоиск, IMDb, Rotten Tomatoes, Metacritic, TMDB и среднее), режиссёр, актёры, ваша оценка от 1 до 10 с заметкой и кнопка «Посмотрел».
  • Распознавание скриншотов: приложение читает текст на картинке прямо на устройстве, находит фильмы в базе и предлагает список с галочками; по желанию на помощь подключается ИИ (Gemini или Claude) для кадров и афиш без названия.
  • Поиск фильма и сериала по названию; «Настройки → Кино»: ключи TMDB, OMDb, ПоискКино и ИИ с проверкой подключения. Фильмы входят в копию данных, PDF и синхронизацию с Google Диском (обложки — как вложения); сами ключи остаются только на устройстве.

1.1.0 Google Диск

  • «Настройки → Google Диск»: заглушка заменена рабочим входом через Google и синхронизацией с Google Диском (папка «iLife»: файл ilife_data.json и папка «Вложения»).
  • Идеи, дела, история цен, имя автора, тема и шрифт сливаются между устройствами поштучно: правки с телефона и ПК не затирают друг друга, удаления тоже передаются.
  • Картинки, музыка, голосовые записи и файлы из идей отправляются на Диск и скачиваются на других устройствах (можно отключить переключателем).
  • Автосинхронизация: после изменений, при открытии, при возвращении в приложение и раз в минуту; без интернета изменения копятся и уходят позже. Client ID можно вписать в поле или в js/config.js.

1.0.0 первая версия

  • «Идеи»: поиск по словам, #хештегам и датам; блок с текстом, хештегами, картинками, музыкой, диктофоном, файлами и кнопкой Spotify; у каждой заметки дата создания и автор.
  • «Дела»: список покупок из My Money с ценами и валютами, расширенный до списка дел со сроками; записи по датам и с именем автора.
  • PDF: отдельные кнопки для идей и для дел.
  • «Настройки»: заглушка Google Диска, Spotify, масштаб 50–200%, пять тем Android, шрифт, профиль, копия данных.
